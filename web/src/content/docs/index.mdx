**Educational Advanced Simulation Malware Laboratory (E.A.S.M.L)** es un framework académico interactivo para estudiar el comportamiento de amenazas informáticas y sus mecanismos de mitigación. Documentación para estudiantes, profesores e investigadores: no solo el código de un ataque, sino su impacto en gobernanza y cumplimiento.
